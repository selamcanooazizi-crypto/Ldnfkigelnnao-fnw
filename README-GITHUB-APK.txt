# ZegaAİ — GitHub üzerinden ücretsiz APK derleme

Bu ZIP'in içeriğini GitHub deposunun ana dizinine yükleyin. ZIP'i GitHub'a tek dosya olarak yüklemeyin; önce çıkarıp içindeki dosyaları yükleyin. `.github/workflows/build.yml` dosyası da dahil olmalı.

## Telefonda yapılacaklar
1. GitHub'da yeni bir repository oluşturun.
2. Bu klasörün İÇİNDEKİ bütün dosyaları repository'ye yükleyin.
3. Repository > Actions bölümüne girin.
4. `ZegaAI APK oluştur` işlemini açın ve başarılı olmasını bekleyin.
5. Tamamlanan çalıştırmanın sayfasında Artifacts bölümünden `ZegaAI-debug-apk` dosyasını indirin.
6. İndirdiğiniz artifact ZIP'ini açıp `app-debug.apk` dosyasını telefona kurun.

Derleme ücretsiz GitHub Actions kullanım kotasına tabidir. Bu proje şu an ilk aşamadır: arayüz ve ayarlar bulunur; gerçek AI modeli ve diğer ileri özellikler henüz ekli değildir.
